# Прогнозирование спроса на специалистов по анализу данных

Учебный проект по дисциплине «Прогнозно-аналитические системы» для профиля «Анализ данных».

## Описание проекта

Цель проекта — разработать прогнозно-аналитическую систему для анализа текущего состояния рынка труда и прогнозирования спроса на специалистов по работе с данными.

Система будет собирать и обновлять открытые данные о вакансиях, выполнять их очистку и агрегацию, строить прогноз количества новых вакансий и представлять результаты в интерактивном дашборде.

## Предметная область

Предметная область проекта — рынок труда в сфере информационных технологий и анализа данных.

В исследование планируется включить следующие направления:

- аналитик данных (Data Analyst);
- продуктовый аналитик (Product Analyst);
- BI-аналитик (BI Analyst);
- специалист по Data Science (Data Scientist);
- инженер данных (Data Engineer).

Точные правила отбора и классификации вакансий будут определены после анализа состава исходных данных.

## Прогнозируемый показатель

Основной прогнозируемый показатель — **количество новых вакансий в сфере анализа данных в России за календарную неделю**.

Планируемый горизонт прогнозирования — **четыре недели**.

Недельная агрегация выбрана для снижения случайных суточных колебаний и сохранения достаточного количества наблюдений для анализа временного ряда и проверки прогнозных моделей.

## Практическая задача

Практическая задача проекта — оценка текущей динамики спроса на специалистов по работе с данными и прогнозирование его изменения на ближайшие четыре недели.

Результаты системы могут использоваться для:

- актуализации образовательных программ;
- планирования карьерных мероприятий;
- определения наиболее востребованных специализаций и навыков;
- подготовки рекомендаций студентам и выпускникам;
- анализа региональной структуры спроса на специалистов.

## Пользователь системы

Основной пользователь системы — **сотрудник карьерного центра университета или руководитель образовательной программы по анализу данных**.

Система должна помочь пользователю ответить на следующие вопросы:

- растёт или снижается спрос на специалистов по работе с данными;
- сколько новых вакансий ожидается в ближайшие четыре недели;
- какие направления и навыки наиболее востребованы;
- в каких регионах сосредоточен спрос;
- как изменяются требования работодателей и предлагаемые зарплаты.

## Источники данных

### 1. Исторические данные о вакансиях

[Открытый датасет вакансий на Mendeley Data](https://data.mendeley.com/datasets/gkfx465zwk/1)

Датасет содержит сведения о вакансиях из нескольких российских сервисов поиска работы за период с июня 2022 года по ноябрь 2023 года. Он будет использован для первоначального анализа доступности и качества исторических данных.

Перед использованием будут проверены:

- состав и типы полей;
- наличие даты публикации вакансии;
- распределение записей по источникам;
- количество вакансий выбранных специальностей;
- наличие дубликатов и пропущенных временных периодов;
- сопоставимость исторических данных с актуальными данными API.

### 2. Актуальные данные о вакансиях

[Официальный API портала «Работа России»](https://trudvsem.ru/opendata/api)

API планируется использовать для регулярного получения новых и изменённых вакансий. Загрузка будет организована инкрементально, с сохранением времени последнего успешного обновления и защитой от появления дубликатов при повторном запуске.

### 3. Внешние календарные факторы

[Производственный календарь](https://xmlcalendar.ru/)

Календарь будет использоваться для определения рабочих, выходных и праздничных дней. Эти данные известны заранее и могут корректно применяться на всём горизонте прогнозирования.

Планируемые календарные признаки:

- число рабочих дней в неделе;
- число выходных и праздничных дней;
- наличие длинных выходных;
- номер недели, месяц и квартал.

## Планируемый результат

Итогом работы должна стать воспроизводимая прогнозно-аналитическая система, включающая:

1. Автоматизированную загрузку данных из открытых источников.
2. Хранение исходных и обработанных данных.
3. Очистку, объединение и контроль качества данных.
4. Разведочный анализ временного ряда и внешних факторов.
5. Формирование календарных, лаговых и оконных признаков.
6. Базовую и не менее двух дополнительных прогнозных моделей.
7. Временную валидацию и сравнение моделей минимум по двум метрикам.
8. Прогноз на четыре недели с оценкой неопределённости.
9. Интерактивный аналитический дашборд.
10. Автоматизированный и воспроизводимый запуск основных процессов.

В качестве дополнительного компонента планируется реализовать бэктестирование моделей на скользящем временном окне.
